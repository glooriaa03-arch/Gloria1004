# Portofolio Nelice Gloria Yekusamon

Website portofolio sederhana yang siap digunakan dengan GitHub Pages.

## File utama
- `index.html` — halaman utama website
- `style.css` — desain website
- `profile.png` — foto profil

## GitHub Pages
Upload ketiga file tersebut ke repository. Kemudian buka:
Settings → Pages → Build and deployment → Deploy from a branch

Pilih branch yang digunakan (misalnya `utama`) dan folder `/ (root)`, lalu Save.
